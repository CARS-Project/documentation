23  Identifiers and scope

23.1 Overview

These columns identify each row of the vehicle table and record why the vehicle is in it.

  • vehicle_id is the row number in the linked input file (Chapter 8). It is unique within one version of the data but not stable between versions: a new delivery renumbers the vehicles (Chapter 14). To follow a vehicle across versions, join on the registration instead (Chapter 24).
  • dup_vrm flags a DVSA registration that appears on more than one row. Duplicates are kept and flagged rather than dropped, because it is not known which row is right.
  • The scope_ flags record the evidence that the vehicle existed at some point from 2005. A vehicle is kept if any of the four is TRUE; the 138.2 million input rows become 93.4 million in-scope vehicles. The flags are not exclusive, and a vehicle often meets several.

How identifiers are assigned is set out in the methodology, section 3.1, and the scope rules in section 3.4. Chapter 9 explains why the table keeps vehicles for which little is known.

23.2 Coverage

Every column in this group has a value for every vehicle. What varies over time is the reason a vehicle is in scope, shown in Figure 23.1. Vehicles first used before 2005 are kept only on evidence of use since then (a mileage, a postcode area or DVLA activity), while almost all of those first used since 2005 are in scope through scope_born. The newest vehicles are in scope almost entirely through scope_born and DVLA activity, as most have not yet had an MOT test.

23.3 Values

How the values of each column change over time, by year of first use, from 1990. Numeric columns and dates show the minimum, lower quartile (Q1), median, upper quartile (Q3) and maximum; other columns show the share of vehicles with each value, with the less common values grouped as All other values and missing values as Blank.

vehicle_id

Row number in the linked input file (stable id for this input).

Each value belongs to one vehicle, so the values are not summarised.

dup_vrm

TRUE if the DVSA registration appears on more than one row of the input.

scope_mileage

In scope because total mileage > 0.

scope_pca

In scope because a PCA is recorded in at least one year.

scope_born

In scope because birth_date is on or after the scope start date.

scope_dvla_activity

In scope because of DVLA activity (tax due, V5C, MOT expiry or first registration) since the scope start date.
