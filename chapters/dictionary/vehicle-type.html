21  Vehicle type

21.1 Overview

These columns say what kind of vehicle each row is. The sources classify vehicles in different ways, none of which matches the categories most analyses want, so the pipeline harmonises them. Chapter 3 explains the classifications and how they relate.

  • body_type is the DfT body type: Cars, Light goods vehicles, Motorcycles, Buses and coaches, Heavy goods vehicles or Other vehicles. It is the usual way to select, for example, cars only. body_type_src records whether it came from the DfT model, the DVLA type approval, the generic model or the MOT test class (methodology, section 4.6).
  • test_class is the MOT test class (1 to 7) and type_approval the European type approval category (M1, N1, L3 and so on). Both take the recorded value where there is one, and otherwise the most common value among vehicles of the same make, model, birth year, fuel and engine size. Each has a _src column saying which (methodology, section 5.6).
  • The supplied columns (_DVLA, _ANON) are the values as received, including the DVLA flag for automated vehicles, which the pipeline does not use.

The vehicle’s colour, wheel plan and weight are described in Chapter 22, Chapter 23 and Chapter 24.

21.2 Coverage

body_type is present for 97% of vehicles and changes little with age (Figure 21.1). The vehicles without one are those whose model could not be matched and which have no type approval or test class to fall back on.

The other harmonised columns depend on what their sources hold:

  • type_approval is rare for vehicles first used before 2000 (26%), because the DVLA rarely records a type approval category for them, and the backfill can only copy values that similar vehicles have. From the mid-2000s it is present for more than 90%.
  • test_class comes from the anonymised MOT data, so it is present only for vehicles that have been tested, or are like vehicles that have. Coverage falls for vehicles first used since 2023, which are too new for their first MOT test: 78% for 2025.

typeApproval_DVLA shares the pattern of every VES field, being present only where a VES record was found (Chapter 30). automatedVehicle_DVLA is present only for some vehicles first used since 2021 (25% of those first used in 2025).

21.3 Values

How the values of each column change over time, by year of first use, from 1990. Numeric columns and dates show the minimum, lower quartile (Q1), median, upper quartile (Q3) and maximum; other columns show the share of vehicles with each value, with the less common values grouped as All other values and missing values as Blank.

body_type

DfT body type: Cars, Light goods vehicles, Motorcycles, Buses and coaches, Heavy goods vehicles or Other vehicles (see body_type_src).

body_type_src

Source of body_type: model (the DfT model string’s body type), type_approval (DVLA type approval, where the generic model has that body type), genmodel (the generic model’s most common body type) or test_class.

test_class

MOT test class: DVSA, else variant backfill.

test_class_src

Source of the matching harmonised column: dvsa or dvla (recorded), variant (same make/model/birth year/fuel/engine size) or model_year_fuel (same make/model/birth year/fuel).

test_class_ANON

Anonymised MOT test class as supplied.

type_approval

Type approval category: DVLA, else variant backfill.

type_approval_src

Source of the matching harmonised column: dvsa or dvla (recorded), variant (same make/model/birth year/fuel/engine size) or model_year_fuel (same make/model/birth year/fuel).

typeApproval_DVLA

As returned by the DVLA Vehicle Enquiry Service.

automatedVehicle_DVLA

As returned by the DVLA Vehicle Enquiry Service.
