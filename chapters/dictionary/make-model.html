21  Make and model

21.1 Overview

DVSA records make and model as free text typed at the test station, so one model can appear in dozens of spellings. The pipeline matches each make and model to the names used in DfT’s vehicle licensing statistics, so CARS results can be compared with and joined to the official figures.

  • make_final and model_final are the cleaned make and DfT generic model (FORD, FIESTA). Use these for analysis.
  • derivative_final is the rest of the DVSA model text, such as trim, engine or body style (ZETEC CLIMATE). It is not standardised.
  • dft_genmodel and dft_model are the DfT names, for joining to DfT tables. dft_model is filled only where the DVSA text is exactly one DfT model string.
  • make_method, model_method and model_confidence record how each match was made and how sure it is. Filter on them to test whether a result depends on the less certain matches.
  • make_DVSA, model_DVSA and make_DVLA are the values as supplied, kept for checking.

The matching is summarised in Chapter 9 and set out in full in the methodology, section 4, including how makes (4.2) and models (4.3) are matched and how the result compares with the DfT counts. The vehicle’s body type, found from the matched model, is described with the other classifications in Chapter 22.

21.2 Coverage

The DVSA make and model are present for almost every vehicle, and the cleaned make for 99.4%: it is blank only where the supplied make is a placeholder such as UNKNOWN. A generic model is found for 96% of vehicles. Matching is a little weaker for the oldest vehicles, first used before 2000 (92%), more of whose models do not appear in the DfT statistics.

The derivative and the exact DfT model string change most over time (Figure 21.1). Both depend on how much detail DVSA’s model text holds, and DVSA records much fuller model names for recent vehicles: the derivative is present for 10% of vehicles first used in 2015, but 95% of those first used in 2024.

The DVLA make is present wherever a VES record was found, which is rarer for older vehicles: see Chapter 31.

21.3 Values

How the values of each column change over time, by year of first use, from 1990. Numeric columns and dates show the minimum, lower quartile (Q1), median, upper quartile (Q3) and maximum; other columns show the share of vehicles with each value, with the less common values grouped as All other values and missing values as Blank.

make_final

Make in the DfT vehicle licensing statistics naming (VEH0220 / VEH0124), upper case; makes DfT spells two ways are merged (inputs/make_aliases.csv). The raw make, upper-cased, where it matches no DfT make; NA where it is a placeholder such as UNKNOWN.

model_final

DfT generic model without the make (“C CLASS”, “FIESTA”); the normalised raw model where it matches no DfT generic model (then dft_genmodel is NA); NA where the model is a placeholder.

derivative_final

The rest of the raw DVSA model text after the words that give the model (trim, engine, body style), upper case, not standardised.

dft_genmodel

DfT GenModel of make_final + model_final, for joining to DfT tables (NA when model_final is not a DfT generic model).

dft_model

DfT model string, when the raw DVSA model is exactly one.

make_method

How make_final was found: exact, punctuation, alias, dvla (the raw make’s vehicles mostly have that DVLA make), prefix, fuzzy (spelling fix), dvla_vehicle (this vehicle’s DVLA make, for a missing or unmatched DVSA make), override, placeholder or unmatched.

model_method

How model_final was found: exact (a DfT model string), generic (a DfT generic model name), prefix, words, fuzzy (spelling fix), ambiguous / make_only (chosen per vehicle from fuel, engine size and year of first use), override, placeholder or unmatched.

model_confidence

Share of the DfT vehicles under the matched text that have this generic model; for ambiguous / make_only, the chosen model’s share of the per-vehicle weight.

make_DVSA

Make as supplied by DVSA.

model_DVSA

Model as supplied by DVSA.

make_DVLA

Make as returned by VES.
