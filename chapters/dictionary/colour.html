27  Colour

27.1 Overview

Both the DVSA and DVLA sources record the vehicle’s colour, but in different ways. The CARS pipeline keeps the values as supplied and does not modify them.

  • primaryColour_DVSA and secondaryColour_DVSA are the colours recorded in the MOT history.
  • colour_DVLA is the colour on the DVLA register, as returned by the Vehicle Enquiry Service (VES).

Vehicles can change colour over time (although most don’t). The DVSA do not provide a record of colour changes over time so the primaryColour_DVSA and secondaryColour_DVSA are likely to be the most recent values. The DVLA VES API also does not provide a record of colour changes over time, but repeated querying of the API may have found some vehicles that have changed colour. However in the main CARS outputs only the most recent colour is kept.

The DVSA and DVLA columns are described among the input data in the methodology, section 2.

27.2 Coverage

The DVSA primary colour is present for every vehicle and the secondary colour for 91%. The secondary colour is less often present for vehicles first used in 2023 and 2024 (41% for 2024) than for older or newer ones (Figure 27.1). A value is not necessarily a colour, though: most vehicles have the secondary colour Not Stated (Figure 27.3), so the column is not particularly useful.

The colour_DVLA, like every VES field, is present only where a VES record was found: 77% of vehicles. When a vehicle does exist in the VES API it almost always has a colour value. The colour_DVLA is less present for those first used before 2010, most of which have left the fleet and so are no longer included in the VES API (Chapter 36).
