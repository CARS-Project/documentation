Appendix B — Catalogue of aggregate tables

The aggregate tables are in three folders. These lists are generated from the index file (README_outputs.csv) that the pipeline writes into each folder. An asterisk in a file name stands for several files: set2_static_by_*.csv is one file for each characteristic. Chapter 12 explains how to use them.

B.1 Mileage tables: tables/mileage/

Details: Vehicles and mileage by postcode area.

File One row per Contents
mileage_by_pca_year_long.csv year x postcode area x plausibility flag Vehicles, total and mean annual mileage for every pca_YYYY value
mileage_by_pca_wide.csv postcode area x plausibility flag, one column per year The total mileage of the long table, pivoted
mileage_by_legit_flag_year.csv year x plausibility flag Vehicles and total mileage: the national totals behind the flag
mileage_by_test_class_year_long.csv year x MOT test class Vehicles and total mileage by the test class as supplied, with its label
mileage_by_test_class_wide.csv MOT test class, one column per year The total mileage of the long table, pivoted
mileage_by_fuel_year_long.csv year x DVSA fuel Vehicles and total mileage by the fuel as supplied, unharmonised
mileage_by_fuel_wide.csv DVSA fuel, one column per year The total mileage of the long table, pivoted
mileage_by_pca_year_body_fuel.csv year x pca_YYYY x body type x fuel group The area table behind the report: vehicles, mileage coverage, mileage, the negative and over-50,000 tails, and age
mileage_by_age_year_body_fuel.csv year x body type x fuel group x age Observed vehicles and their plausible mileage by age, for vehicles in a real postcode area
mileage_distribution_by_year_body.csv year x body type x plausibility flag x mileage band Recorded mileage in bands of 1,000 to 50,000, then wider

Details: Fleet profile tables.

File Form Contents

profile_categorical_by_year_age.csv Long The same, split by age band
profile_continuous_by_year.csv Long year x body type x measure: n, mean, sd, min, p10, p25, p50, p75, p90, max

a1_counts_<body_type>.csv Analysis 1 Rows = years, columns = characteristic: category, cells = vehicles

a4_mean_mileage_<body_type>_by_age.csv Analysis 4 Rows = years x age band, columns = characteristic: category, cells = mean mileage
