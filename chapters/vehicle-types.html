3  Classifying vehicles

“Car” seems a simple idea, but the UK uses at least three different ways of dividing vehicles into types, each made for a different purpose and each drawing the boundaries in slightly different places. The CARS data carries all three, so it is worth knowing how they differ.

Scheme Made for Set by In the CARS data
MOT test class Deciding which test a vehicle takes DVSA test_class
Type approval category Deciding which construction and safety rules a new vehicle must meet UN / EU regulation, now GB type approval type_approval
Body type Official statistics DfT body_type

3.1 MOT test classes

The MOT test class sets which version of the test a vehicle takes, which depends on what it is and how heavy it is. Most of the vehicles in the data are class 4.

Two features of the classes often surprise people:

  • Class 4 is not “cars”. It includes vans up to 3,000kg, motor caravans, taxis and minibuses with up to 12 passenger seats. It excludes the heaviest vans (3,000–3,500kg), which are class 7.
  • Class 5 is mostly minibuses. Large buses and coaches take the separate annual test, so the buses in MOT data are small ones.

In the CARS data, test_class_ANON is the test class as supplied in the anonymised MOT data, and test_class fills its gaps from similar vehicles (Chapter 9). The supplied class is missing for every vehicle in Northern Ireland and for many vehicles never tested.

3.2 Type approval categories

Before a new model can be sold, its design must be approved as meeting the rules for its category: crash protection, braking, lighting, emissions and so on. The categories come from international (UN and EU) regulation, carried into GB type approval after the UK left the EU.

The type approval category and the MOT class are separate schemes, but the category largely decides the class:

  • M1 cars take a class 4 MOT.
  • M2 minibuses take class 4 with up to 12 passenger seats, or class 5 with more: for minibuses, seat count decides.
  • M3 buses and coaches mostly take the separate annual test.
  • N1 vans take class 4 up to 3,000kg design gross weight, or class 7 from 3,000kg to 3,500kg: for vans, weight decides.
  • N2 and N3 goods vehicles take the heavy goods vehicle annual test, not an MOT.

In the CARS data, typeApproval_DVLA is the category as the DVLA register records it, and type_approval fills gaps from similar vehicles. The DVLA records a type approval category for most vehicles registered in recent decades, but rarely for older ones.

Type approval against test class in the data

Table 3.4 counts the vehicles in the vehicle table for each combination of type approval category and MOT test class. The rules above show up clearly in the recorded values:

  • 85.0% of M1 cars are class 4; almost all the rest have no recorded test class.
  • N1 vans divide between class 4 (56.5%) and class 7 (25.0%), by weight.
  • M2 minibuses are mostly class 5 (71.2%), with the smaller ones in class 4.
  • L3 motorcycles divide between class 1 and class 2 by engine size, and L5 tricycles are mostly class 3.
  • N2 and N3 lorries, M3 buses and coaches, and T tractors almost never have an MOT test class, because they take the annual test or are exempt.

ImportantPitfall: filled values can make impossible combinations

The harmonised type_approval and test_class are each filled from the most common value among similar vehicles, independently of each other. Filling covers far more vehicles, but it also creates combinations the rules do not allow, such as 110,616 M1 cars in class 1 (the motorcycle class). Use the recorded values when the relationship between the two schemes matters.

The DVLA field also holds 20,872 values that are not type approval categories, such as numbers, older national codes and lower-case variants; they are shown as Other code.

3.3 DfT body types

DfT’s vehicle licensing statistics divide vehicles into body types:

  • Cars
  • Light goods vehicles (LGVs): goods vehicles up to 3.5 tonnes, the N1 category
  • Motorcycles, including mopeds and scooters
  • Buses and coaches
  • Heavy goods vehicles (HGVs)
  • Other vehicles: tractors, three-wheelers, special vehicles and so on

Body type is the classification CARS uses for most of its tables, because it matches the official statistics. The vehicle table’s body_type column is derived from the vehicle’s make and model, matched to DfT’s names; where the model does not settle it, from the type approval category; and failing that, from the test class (Chapter 9).

3.4 How the schemes compare

The schemes draw their lines in different places, which matters whenever CARS results are compared with other statistics:

  • A class 4 count includes vans up to 3,000kg and minibuses with up to 12 seats; a DfT cars count includes neither.
  • A DfT light goods vehicles count includes the 3,000–3,500kg vans that are MOT class 7.
  • Taxis and private hire vehicles are ordinary M1 cars for type approval and DfT, but take their first MOT at one year rather than three.
  • DfT’s road traffic statistics use their own definitions again, based on how vehicles are recognised in traffic counts.
TipWhich should I use?

For comparisons with DfT statistics, use body_type. For questions about the MOT test itself, or to reproduce earlier CARS outputs, use test_class. The churn tables (Chapter 12) are built on class 4 vehicles, so they include vans and small minibuses alongside cars.
